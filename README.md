## ✨ Fonctionnalités

| Fonctionnalité | Description |
|----------------|-------------|
| 🎨 **10 Templates Uniques** | Du classique au moderne, chaque template a sa propre mise en page |
| 🧠 **25 Agents IA** | 5 agents spécialisés par section (Profil, Expériences, Formation, Compétences, Lettre) |
| 🌍 **6 Langues** | Français, English, Español, Deutsch, Italiano, Português |
| 📄 **CV + Lettre** | Génération simultanée des deux documents |
| 🖨️ **Export PDF & HTML** | Téléchargez vos documents au format PDF ou HTML |
| 💾 **Sauvegarde Auto** | Vos données sont sauvegardées dans votre navigateur |
| 🌓 **Thème Clair/Sombre** | Interface adaptée à vos préférences |
| 📱 **Responsive** | Fonctionne sur mobile, tablette et desktop |

## 🧠 Les 25 Agents IA

### 👤 Profil (5 agents)

| Agent | Action |
|-------|--------|
| Rédacteur Bio | Reformule votre profil professionnel |
| Titre Accrocheur | Rend votre titre plus percutant |
| Correcteur Pro | Corrige style et ponctuation |
| Mots-clés SEO | Ajoute des mots-clés recherchés |
| Résumé Percutant | Ajoute une accroche impactante |

### 💼 Expériences (5 agents)

| Agent | Action |
|-------|--------|
| Rédacteur Pro | Améliore le style des missions |
| Optimiseur CV | Ajoute des mots-clés stratégiques |
| Analyseur de Poste | Adapte les missions au poste visé |
| Valoriseur | Ajoute des réalisations quantifiées |
| Formateur | Ajoute des compétences liées |

### 🎓 Formation (5 agents)

| Agent | Action |
|-------|--------|
| Rédacteur Diplômes | Rédige une description pour vos formations |
| Valoriseur Mentions | Suggère une mention valorisante |
| Analyseur de Poste | Relie vos formations au poste visé |
| Certifications Suggérées | Ajoute une certification pertinente |
| Extracteur Compétences | Extrait des compétences de vos diplômes |

### ⚡ Compétences (5 agents)

| Agent | Action |
|-------|--------|
| Suggéreur Compétences | Propose des compétences pertinentes |
| Niveaux Optimisés | Ajuste les niveaux de maîtrise |
| Langues Suggérées | Complète vos langues parlées |
| Centres d'intérêt Pro | Suggère des intérêts valorisants |
| Mots-clés ATS | Ajoute des mots-clés pour les logiciels de tri |

### ✉️ Lettre de motivation (5 agents)

| Agent | Action |
|-------|--------|
| Rédacteur Pro | Génère la lettre complète |
| Accroche Percutante | Renforce la phrase d'ouverture |
| Renforcateur Arguments | Ajoute un argument concret |
| Personnalisateur | Adapte la lettre à l'entreprise visée |
| Clôture Convaincante | Renforce la phrase de conclusion |
